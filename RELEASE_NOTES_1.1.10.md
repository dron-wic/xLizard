## Портативная сборка для Windows

Архив содержит готовое приложение **без установки Python**.

### Установка
1. Скачайте `xLizard-1.1.10-windows-x64.zip`
2. Распакуйте архив в любую папку (например `C:\Tools\xLizard\`)
3. Запустите `xLizard.exe` из распакованной папки

> Важно: не удаляйте папку `_internal` рядом с exe — она нужна для работы.
> Настройки — в **`xlizard.json`** рядом с exe.

### Что нового в 1.1.10
- В «О метриках» — явные отличия схожих метрик (CCN↔CogC, NLOC↔Length, ND↔Depth, CALLS↔CALLING и др.)
- В каждом файле HTML (`file-card`): сводная таблица файловых метрик (Logic, Cond, LOC и др.)
- Колонка «Строки» в таблице функций; дополнительные бейджи в шапке файла

### Состав релиза
- `xLizard.exe` — GUI-приложение
- `xlizard.json` — настройки по умолчанию
- `_internal/` — зависимости runtime (не удалять)

### Системные требования
- Windows 10/11, x64
- Python не требуется
