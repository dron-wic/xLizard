## Портативная сборка для Windows

Архив содержит готовое приложение **без установки Python**.

### Установка
1. Скачайте `xLizard-1.1.9-windows-x64.zip`
2. Распакуйте архив в любую папку (например `C:\Tools\xLizard\`)
3. Запустите `xLizard.exe` из распакованной папки

> Важно: не удаляйте папку `_internal` рядом с exe — она нужна для работы.
> Настройки — в **`xlizard.json`** рядом с exe.

### Что нового в 1.1.9
- Формула суммарной оценки **явно на вкладке «Обзор»** HTML
- Веса формулы настраиваются в **«Пороги»** и в `xlizard.json` → `quality_score`
- Горизонтальный скролл таблицы метрик функций (все колонки доступны)

### Состав релиза
- `xLizard.exe` — GUI-приложение
- `xlizard.json` — настройки по умолчанию (включая `quality_score`)
- `_internal/` — зависимости runtime (не удалять)

### Системные требования
- Windows 10/11, x64
- Python не требуется
