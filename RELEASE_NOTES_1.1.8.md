## Портативная сборка для Windows

Архив содержит готовое приложение **без установки Python**.

### Установка
1. Скачайте `xLizard-1.1.8-windows-x64.zip`
2. Распакуйте архив в любую папку (например `C:\Tools\xLizard\`)
3. Запустите `xLizard.exe` из распакованной папки

> Важно: не удаляйте папку `_internal` рядом с exe — она нужна для работы.
> Настройки теперь в **`xlizard.json`** (рядом с exe). Старый `thresholds.txt` при первом запуске может быть мигрирован автоматически.

### Как пользоваться
1. Укажите **файл** или **папку** с исходниками C/C++ (`.c`, `.h`, `.cpp`, `.hpp`, …)
2. При необходимости задайте путь для HTML-отчёта
3. Настройте пороги в **«Пороги»** или в `xlizard.json`
4. При необходимости включите **HIS-метрики** (по умолчанию выкл.)
5. Нажмите **«Анализировать»**
6. Откроется HTML-отчёт (если включено «Открыть в браузере»)

Значение метрики **выше** `limit` считается превышением.

### Что нового в 1.1.8
- Единый **`xlizard.json`**: пороги, soft %, тема, флаг HIS
- Опциональный пакет **HIS** (GOTO / RETURN / PATH / CALLS / CALLING)
- Суммарная оценка качества **0–100** на вкладке «Обзор»:
  - мягкая зона = `soft_pct` % над `limit`, жёсткая — выше;
  - штраф: 15×доля мягких функций + 45×доля жёстких + файловый штраф (до 20);
  - статусы Норма / Допустимо / Внимание / Критично; топ превышений
- Колонка **Length**, подсказки с **Мягкое: N%**
- Немодальные «Пороги» / «О метриках», копирование журнала
- Стабильный лог в portable exe (`pythonw` / `runw`)

### Системные требования
- Windows 10/11, x64
- Python не требуется

### Состав релиза
- `xLizard.exe` — GUI-приложение
- `xlizard.json` — настройки по умолчанию
- `_internal/` — зависимости runtime (не удалять)

Полный список: см. `CHANGES.rst` / README в репозитории.
